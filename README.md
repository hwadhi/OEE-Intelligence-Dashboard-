# 🏭 OEE Intelligence Dashboard



## Problem Statement
Manufacturing supervisors at HPDC lines 
rely on manual Excel tracking to monitor OEE — 
causing delayed identification of loss patterns 
and slow corrective action.

## Solution
Automated shift-wise OEE monitoring dashboard 
that classifies losses, detects anomalies using ML, 
and benchmarks against world-class standards.

## Key Features
- ✅ Automatic OEE calculation — Availability × Performance × Quality
- ✅ AI-based anomaly detection using Isolation Forest
- ✅ Pareto analysis of loss contributors  
- ✅ Shift and machine-wise benchmarking
- ✅ World class comparison (85% OEE target)

## Tech Stack
Python | Pandas | Streamlit | Plotly | Scikit-learn

## Live Dashboard
[Click here to view live dashboard](https://heramb-oee-dashboard.streamlit.app/)

## Dataset
Synthetic dataset modeled on HPDC line 
observations from CIE Automotive internship.
60-day, 3-shift, 4-machine production data.
